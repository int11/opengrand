# Commercial licensing

OpenGrand is offered under two licenses (dual licensing):

1. **GNU GPL v3** with the [additional permission](../LICENSE-EXCEPTION.md) for combining it with Kawai's system
   firmware - free of charge, for everyone, for any purpose, as long as you follow the GPL. This covers
   personal use, modification and redistribution of source and binaries under the GPL.
2. **A commercial license** from the copyright holder, for uses the GPL does not allow - for example
   shipping OpenGrand (or code from it) inside a closed-source product or app, combining it with other
   proprietary software, or distributing it without providing the Corresponding Source.

## Who can grant a commercial license

The project maintainer holds the copyright in OpenGrand, together with the rights contributors license to
the maintainer under the [Contributor License Agreement](CLA.md). That agreement is what makes it possible
to offer a commercial license covering the whole project.

A commercial license covers OpenGrand's own code only. It does not grant any rights in Kawai's firmware,
trademarks or other assets, and it does not change the requirement that you obtain Kawai's software
yourself.

## How to ask

Open a GitHub issue titled **"Commercial license inquiry"** with a short description of the intended use
(no confidential details needed at first), or contact the maintainer through the contact options on the
maintainer's GitHub profile. Terms are agreed case by case.

If you are unsure whether your use needs a commercial license, ask - most non-commercial and open-source
uses do not.
